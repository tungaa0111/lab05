## 3. Ажлын зорилго

Энэ лабораторийн ажлаар бүртгэлийн API-г янз бүрийн нөхцөлд ажиллуулж шалгасан. Бүртгэл амжилттай болохоос гадна оюутан байхгүй, идэвхгүй байх, хичээл олдохгүй байх зэрэг алдааны нөхцөлүүдийг туршиж үзсэн.

## 4. Хийсэн тестүүд

Нийт 10 тестийн тохиолдол бэлдсэн.

1. Happy Path – оюутан хичээлдээ амжилттай бүртгүүлэх
2. Inactive Student – идэвхгүй оюутан бүртгүүлэх
3. Missing Field – хүсэлтэд шаардлагатай мэдээлэл дутуу байх
4. No Course – бүртгүүлэх хичээл байхгүй байх
5. No Prerequisites – урьдчилсан нөхцөлгүй хичээлд бүртгүүлэх
6. No Student – оюутны мэдээлэл байхгүй байх
7. Prerequisites Met – өмнөх хичээлийн нөхцөлөө хангасан байх
8. Prerequisites Not Met – өмнөх хичээлийн нөхцөлөө хангаагүй байх
9. Double Error – оюутан болон хичээл хоёулаа байхгүй байх
10. Double Error – оюутан идэвхгүй, хичээл байхгүй байх

## 5. Туршилтын үр дүн

### 5.1 Үндсэн тест

Үндсэн Collection-ийг Newman ашиглан ажиллуулахад 10 тест бүгд амжилттай болсон.

- Нийт хүсэлт: 24
- Assertion: 21
- Амжилтгүй хүсэлт: 0
- Амжилтгүй шалгалт: 0

Үр дүнг `results/newman-pass.txt` файлд хадгалсан.

### 5.2 Буруу үр дүн шалгах туршилт

Нэг тестийн хүлээгдэж буй үр дүнг зориуд буруу утгаар сольж ажиллуулсан. Ингэхэд Newman тухайн шалгалтыг алдаа гэж илрүүлсэн.

`expected 'OK' to deeply equal 'WRONG_RESULT'` гэсэн алдаа гарсан. Newman-ийн exit code 1 болсон. Энэ нь буруу үр дүнг илрүүлж байгааг харуулсан.

Үр дүн: `results/newman-fail.txt`

### 5.3 Сервер унтраалттай үеийн туршилт

API серверийг унтраасны дараа Collection-ийг дахин ажиллуулсан. Энэ үед сервертэй холбогдож чадаагүй бөгөөд `ECONNREFUSED` гэсэн алдаа гарсан.

Ингэснээр сервер ажиллахгүй үед хүсэлтүүд амжилтгүй болж байгааг шалгасан.

Үр дүн: `results/newman-down.txt`

## 6. Файлын бүтэц

- `server.js` – API серверийн файл
- `lab05-collection.json` – үндсэн тестийн Collection
- `lab05-collection-fail.json` – буруу шалгалттай Collection
- `scripts/` – Collection үүсгэх скрипт
- `results/` – тест ажиллуулсан үр дүнгийн файлууд
- `README.md` – лабораторийн ажлын тайлбар
- `.gitignore` – Git-д оруулахгүй файлуудын тохиргоо

## 7. Дүгнэлт

Энэ лабораторийн ажлаар Postman болон Newman ашиглан API тест хийж сурлаа. Эхлээд бүртгэлийн API-ийн хэвийн ажиллагааг шалгаж, дараа нь янз бүрийн алдааны нөхцөлүүдийг туршсан. Нийт 10 тест ажиллуулахад үндсэн тестүүд бүгд амжилттай болсон. Мөн зориуд буруу хүлээлт оруулахад Newman алдааг илрүүлж байгааг харсан. Серверийг унтрааж туршихад холболтын алдаа гарсан. Тестийн үр дүнг тус тусад нь файлд хадгалсан. Энэ ажлаар API-г зөвхөн амжилттай үед нь биш, алдаа гарсан үед ч шалгах хэрэгтэйг ойлгосон.
